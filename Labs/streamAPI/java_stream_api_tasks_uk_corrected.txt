Практичні задачі з Java Stream API

У кожній задачі основну
обробку даних потрібно реалізувати засобами Java Stream API та
лямбда-виразів. Звичайні цикли дозволено використовувати там, де вони
доречні для керування станом або послідовного читання даних.

Загальні вимоги

1. Використовуйте Stream API для фільтрації, перетворення, сортування та
   агрегування даних, коли це робить розв’язок зрозумілішим.
2. Для числових обчислень за можливості використовуйте IntStream,
   LongStream або DoubleStream.
3. Розділяйте розв’язок на логічні етапи та, за потреби, допоміжні методи.
4. Не змінюйте початкові масиви й колекції, якщо умова прямо цього не
   вимагає.
5. Закривайте потоки, пов’язані з файлами, за допомогою
   try-with-resources.
6. Обробляйте некоректні вхідні дані та помилки читання з повідомленням,
   яке допомагає визначити проблему. Не пропускайте файли або записи
   мовчки.
7. Поясніть, які операції Stream API у вашому розв’язку є проміжними, а
   які — термінальними.

Задача 1. Читання файлів і статистичний аналіз вимірювань

Умова

У каталозі, заданому користувачем, та його підкаталогах зберігаються
текстові файли з результатами експерименту. Потрібно знайти всі звичайні
файли, назви яких відповідають шаблону log*.txt, прочитати їх і виконати
статистичний аналіз усіх отриманих значень. Символ * означає будь-яку
послідовність символів, зокрема порожню.

Формати вхідних файлів

- Файли мають розширення .txt і кодування UTF-8. Кожен непорожній рядок
  містить одне скінченне число типу double у десятковому форматі.
  Пробіли на початку та наприкінці рядка дозволені.
- Назва файлу має починатися з log і закінчуватися на .txt. Порівняння
  назви та розширення не чутливе до регістру. Символічні посилання
  обходити не потрібно.
- Усі значення мають бути скінченними числами. Якщо файл має неправильний
  формат або його не вдається прочитати, програма повинна повідомити про
  помилку із зазначенням шляху до файлу та завершити обробку з помилкою.
- У знайдених файлах має бути принаймні одне вимірювання загалом.

Розробіть програму, яка:

1. Рекурсивно знаходить усі звичайні файли, назви яких відповідають
   шаблону log*.txt.
2. Читає значення з кожного знайденого текстового файлу за рядками.
3. Об’єднує прочитані значення для подальшого аналізу.
4. Обчислює кількість вимірювань, середнє арифметичне, мінімальне та
   максимальне значення.
5. Виводить усі вимірювання у порядку зростання.
6. За заданим невід’ємним числом delta знаходить вимірювання x_i, для
   яких |x_i - mean| > delta, де mean — середнє арифметичне всіх
   вимірювань.
7. Обчислює середнє після вилучення одного мінімального та одного
   максимального значення. Якщо всі значення однакові, результатом має
   бути це значення. В інших випадках, якщо після вилучення крайніх
   значень не залишається жодного вимірювання, повідомте, що середнє
   обчислити неможливо.

Вхідні дані

- Шлях до каталогу з файлами вимірювань.
- Невід’ємне скінченне число delta.

Результат

Виведіть знайдені файли, кількість вимірювань, середнє, мінімум і
максимум, вимірювання у відсортованому порядку, значення з відхиленням
понад delta та середнє після вилучення крайніх значень або пояснення,
чому його неможливо обчислити.

Додаткові запитання

1. Які операції Stream API зручно застосувати для пошуку файлів, читання
   текстових рядків і статистичного аналізу?
2. Чим DoubleStream відрізняється від Stream<Double> під час обробки
   числових значень?
3. Чому потік, отриманий через Files.walk або Files.lines, потрібно
   закривати?

Задача 2. Дослідження простих чисел

Умова

Простим називається натуральне число, більше за 1, яке має рівно два
додатні дільники: 1 і саме це число.

Для цілих чисел a та b, що задовольняють умову 2 <= a <= b, виконайте
дослідження простих чисел на відрізку [a, b], включно з обома межами.

Розробіть програму, яка:

1. Формує послідовність усіх простих чисел від a до b включно.
2. Визначає кількість знайдених простих чисел.
3. Знаходить усі пари простих чисел-близнюків на цьому відрізку. Пара
   простих чисел-близнюків — це два прості числа, різниця між якими
   дорівнює 2; наприклад, (11, 13).
4. Для кожного знайденого простого числа обчислює число, отримане
   розворотом його десяткового запису, і виводить пару чисел, якщо
   розвернуте число також є простим та відрізняється від початкового.
   Наприклад, для 13 розвернутим числом є 31.

Під час перевірки простоти достатньо перевіряти дільники від 2 до
квадратного кореня з n включно. Реалізація має коректно обробляти
розворот числа без переповнення типу int.

Вхідні дані

Два цілі числа a та b, де 2 <= a <= b.

Результат

Виведіть усі прості числа на відрізку, їхню кількість, усі пари
простих-близнюків і всі пари різних простих чисел, у яких одне число є
розвернутим записом іншого.

Додаткові запитання

1. Які частини розв’язку доцільно винести в окремі методи?
2. Як за допомогою IntStream сформувати початкову послідовність чисел?
3. Чому для перевірки дільників достатньо дійти до квадратного кореня?

Задача 3. Обробка матриці дійсних чисел

Умова

Матриця записана в бінарному файлі з розширенням .bin. Файл має містити
додатні цілі розміри матриці: спочатку кількість рядків m, потім
кількість стовпців n. Після них записано m * n скінченних чисел типу
double у порядку рядків. Формат відповідає методам
DataOutputStream.writeInt і DataOutputStream.writeDouble. Після останнього
елемента додаткових байтів бути не повинно. Скаляр k також є скінченним
числом типу double.

Розробіть програму, яка:

1. Обчислює суму та середнє арифметичне всіх елементів матриці.
2. Визначає кількість додатних, від’ємних і нульових елементів. Нулем
   вважається значення, для якого x == 0.0.
3. Обчислює суму елементів кожного рядка.
4. Знаходить елемент із найбільшим модулем і виводить його значення та
   позицію (номер рядка і стовпця). Нумерація рядків і стовпців має
   починатися з 0. Якщо максимальний модуль мають кілька елементів,
   виведіть перший у порядку обходу рядків зліва направо.
5. Створює та виводить нову матрицю, у якій кожен елемент дорівнює
   відповідному елементу початкової матриці, помноженому на k. Початкову
   матрицю змінювати не можна.
6. Виводить усі елементи початкової матриці у порядку зростання.

Для перетворення рядків матриці на єдину послідовність елементів
розгляньте використання Arrays.stream(matrix) разом із flatMapToDouble.

Вхідні дані

- Шлях до бінарного файлу матриці.
- Скінченне число k.

Результат

Виведіть суму та середнє, кількість додатних, від’ємних і нульових
елементів, суми рядків, елемент із найбільшим модулем та його
координати, нову матрицю після множення на k і відсортовані елементи
початкової матриці.

Додаткове запитання

Чому Arrays.stream(matrix) створює потік рядків типу double[], а не
потік окремих чисел матриці?

Задача 4. Аналіз кандидатів на розв’язок задачі оптимізації

Умова

Кожен кандидат на розв’язок задачі з двома змінними описується трьома
скінченними числами: координатами x та y і значенням цільової функції
objective у цій точці. Кандидати зберігаються у списку об’єктів типу
Solution:

record Solution(double x, double y, double objective) {}

Кандидати записані в текстовому CSV-файлі UTF-8: один кандидат на рядок,
три розділені комами поля у порядку x,y,objective. Перший рядок може
містити заголовок x,y,objective. Поля не беруться в лапки; порожні
рядки дозволено пропускати. Усі три значення мають бути скінченними.

Розглядається задача мінімізації. Кандидат є допустимим, якщо
x >= 0, y >= 0 та x + y <= 1.

Розробіть програму, яка:

1. Відбирає допустимі кандидати та визначає їхню кількість.
2. Знаходить допустимого кандидата з найменшим значенням objective.
3. Виводить до K найкращих допустимих кандидатів у порядку зростання
   objective. Якщо значення objective однакові, використовуйте
   координату x, а потім y як критерії для стабільного порядку.
4. Визначає кількість допустимих кандидатів, для яких objective <= L.
5. Групує допустимі кандидати за значенням objective в такі інтервали:
   - objective < 0;
   - 0 <= objective < 10;
   - 10 <= objective < 100;
   - objective >= 100.
6. Виводить кількість кандидатів у кожній групі, зокрема нуль, якщо
   група порожня.

Якщо допустимих кандидатів немає, повідомте про це. Не намагайтеся
отримати мінімум або перші K елементів порожньої послідовності.
Вважайте, що K — натуральне число, а L — скінченне число типу double.

Вхідні дані

- Шлях до CSV-файлу з кандидатами.
- Натуральне число K.
- Скінченне число L.

Результат

Виведіть кількість допустимих кандидатів; найкращого кандидата, якщо
він існує; до K найкращих кандидатів; кількість кандидатів зі значенням
objective не більше L; кількість кандидатів у кожному інтервалі.

Додаткове запитання

Як за допомогою Comparator задати порядок кандидатів за зростанням
objective та як змінити його на спадний?

Задача 5. Аналіз числової послідовності

Умова

Дано непорожній масив sequence дійсних чисел довжини n, де n >= 1. Для
індексу i, де 1 <= i <= n - 2, елемент a_i є:

- локальним максимумом, якщо a_i > a_(i-1) та a_i > a_(i+1);
- локальним мінімумом, якщо a_i < a_(i-1) та a_i < a_(i+1).

Розробіть програму, яка:

1. Знаходить усі локальні максимуми та їхні індекси.
2. Знаходить усі локальні мінімуми та їхні індекси.
3. Визначає кількість переходів від строго зростання до строго
   спадання та від строго спадання до строго зростання. Такі переходи
   відповідають локальним максимумам і мінімумам відповідно. Рівні
   сусідні значення не утворюють переходу.
4. Знаходить найдовший неперервний строго зростаючий фрагмент.
5. Виводить початковий і кінцевий індекси фрагмента, його довжину та
   самі елементи. Індекси починаються з 0.
6. Якщо найдовших фрагментів однакової довжини кілька, виводить той,
   що починається раніше.

Фрагментом вважається послідовність елементів, розташованих на
послідовних позиціях у вихідному масиві. Видаляти або переставляти
елементи не можна. Якщо n < 3, локальних максимумів і мінімумів немає.
Якщо в масиві немає пари сусідніх елементів, що строго зростає, найдовший
зростаючий фрагмент складається з одного елемента; у разі однакових
значень виберіть елемент з найменшим індексом.

Приклад

Для послідовності

[1, 3, 5, 4, 2, 6, 8, 7, 9, 11, 10]

локальними максимумами є 5 з індексом 2, 8 з індексом 6 і 11 з індексом
9. Найдовший строго зростаючий фрагмент — [1, 3, 5] з індексами від 0
до 2 включно; його довжина дорівнює 3. Фрагмент [7, 9, 11] також має
довжину 3, але за правилом вибору потрібно вивести той, що починається
раніше.

Вхідні дані

Непорожній масив sequence дійсних чисел.

Результат

Виведіть локальні максимуми та мінімуми з індексами, кількість
переходів кожного виду та найдовший строго зростаючий неперервний
фрагмент із його межами й довжиною.

Додаткове запитання

Які частини задачі природно виражаються через IntStream.range, а які
потребують збереження стану або окремого проходу?
